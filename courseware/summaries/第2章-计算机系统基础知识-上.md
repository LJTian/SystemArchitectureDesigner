## 一、概述与硬件

### 系统与体系结构
- **计算机系统**：用于数据管理的硬件、软件及网络组成；按人的要求接收/存储信息，自动处理并输出结果。
- **冯·诺依曼**：硬件划分为 5 部分；现实中控制单元与运算单元集成于处理器，I/O 常按传输过程划分为总线、接口、外部设备。

### 处理器与指令集（★★★ / ★★）
- CPU 是运算与控制核心；指令集分 **CISC**（如 x86）与 **RISC**（如 ARM、Power）。
- 另有 GPU（大量并行核，深度学习常用）、DSP（实时数字信号处理）、FPGA 等。
- **CISC vs RISC（对照记）**

| 维度 | CISC | RISC |
|------|------|------|
| 指令 | 数量多、使用频率差大、可变长 | 数量少、频率相近、定长、多为单周期 |
| 访存 | 指令可直接在主存处理 | 仅 Load/Store 访存 |
| 寻址 | 方式多 | 支持少 |
| 实现 | 微程序控制为主 | 硬布线为主，适合流水线；编译要求高 |

- **易错点**：RISC 特点是「指令少、格式种类少、长度固定」，**不是**寻址方式多；RISC-V 是开放 ISA，**不是** x86 的一种。

### 层次化存储与 Cache（★★★）
- 分层目的：解决容量、价格、速度矛盾；依据是**程序局部性原理**。
- 四层（按与 CPU 距离）：片上缓存（SRAM）→ 片外/平台 Cache（L2/L3）→ 主存 DRAM → 外存（磁带/磁盘/光盘/Flash）。
- 常见表述：寄存器 / Cache / 主存 / 辅存；目前三级体系常说 Cache–主存–辅存；主存+辅存构成虚拟存储器。
- **速度**：有寄存器时寄存器最快，否则 Cache 最快。
- Cache 存主存副本；**时间局部性**（循环等）、**空间局部性**（顺序/数组）。
- 命中则直接访 Cache，否则访主存；平均访问时间  
  \(t_a = h \cdot t_1 + (1-h) \cdot t_2\)。
- **例题套路**：指令与数据合一 Cache 时，分段算取指与取数时间再加权（如约 1/5 指令多访一次操作数）。

### 总线、接口、外设
- **总线位置**：内总线（片上）/ 系统总线（CPU·主存·I/O）/ 外部总线（板与外设或系统间，通信总线）。
- **并行**如 PCI、PCIe、ATA；**串行**如 USB、SATA、CAN、RS-232/485、以太网等。
- 接口：显示（HDMI/DVI）、音频、网络（RJ45 等）、PS/2、USB、SATA、LPT、RS-232 等。
- 外设覆盖通用 I/O、移动穿戴传感器，以及工控/航空/医疗等专用设备。

## 二、计算机软件

### 软件分类与操作系统
- **系统软件**：不依赖特定应用域，管控资源并提供运行平台；**应用软件**：面向具体问题。
- **内核**：进程/存储/文件/设备管理；驻留内存、高优先级、可执行特权指令。
- **四大特征（★）**：并发性、共享性、虚拟性、不确定性（走走停停）。
- **分类要点（★★）**
  - **批处理**：单道 vs 多道（多道、宏观并行、微观串行）。
  - **分时**：时间片轮转；多路性、独立性、交互性、及时性。
  - **实时**：足够快并在**被控对象允许时间范围**内响应；可靠性要求高，交互要求相对不高。
  - **网络 OS**：硬件独立性、多用户与安全保护等。
  - **分布式 OS**：无主次、透明性/可靠性/高性能；网络 OS 的更高级形式。
  - **嵌入式 OS**：微型化、可定制、实时性、可靠性、易移植（HAL/BSP）。

### 数据库类型（概览）
- 早期：层次、网状、关系；现今常见关系型与非关系型。
- 按存储体系还可分：关系（二维表）、键值、列存储、文档（XML/JSON/BSON）、搜索引擎库等。

### 文件系统（★★～★★★）
- **逻辑结构**：记录式（有结构）vs 流式（无结构）。
- **物理结构**：连续（顺序）、链接（串联）、索引；大文件索引表可用链接或多重索引。
- **索引节点混合索引（高频计算）**：直接块 + 一级/二级（甚至三级）间接；按盘块大小与地址项字节数算可表示最大文件长度，并判断某逻辑块号用哪级索引。
- **空闲空间管理**：空闲区表、**位示图**、空闲块链、成组链接（UNIX）。
  - 位示图：每位对应一物理块，0 空闲 / 1 占用；注意字号、位号是否从 0 起，算「第几字的第几位」。
- **共享**：硬链接（多名共一索引结点）vs 符号链接（路径映射）。
- **保护**：存取控制矩阵、存取控制表、用户权限表、密码加密等。

### 中间件与构件（★★）
- 中间件位于 OS/网络/数据库之上、应用之下；类型含：消息、事务（交易）、数据存取、Web 服务器、安全、跨平台（如 CORBA）、专用平台、网络中间件等。
- **构件**：自包容、可复用；外部仅经接口访问；组装优缺点（扩展/并行开发 vs 设计难度/性能让步/学习与第三方质量风险）。
- **CORBA**：ORB（软总线）+ 公共服务 + 公共设施；POA 中介请求到**伺服对象 Servant**；CCM 含抽象模型、容器、打包配置。
- **J2EE/EJB**：Session / Entity / Message-Driven Bean 职责不同（会话短暂、实体持久、消息异步）。

## 三、嵌入式系统及软件

### 组成与特点（★～★★）
- **组成**：嵌入式处理器、支撑硬件、嵌入式 OS、支撑软件、应用软件。
- **特点**：专用性强、技术融合、软硬一体偏软件、资源少于通用机、代码固化非易失存储、需专用开发环境、体积成本与实时性、安全可靠要求高等。

### 分类与软件层次
- **实时**：强实时 / 弱实时；正确性依赖逻辑**与**结果产生时间。
- **安全攸关**：失效可致伤亡/重大损失；对比非安全攸关。
- **软件层次**：硬件层 → 抽象层（HAL/BSP）→ OS 层 → 中间件层 → 应用层；可配置、可剪裁。
- **软件特点（★★★）**：可剪裁、可配置、强实时、安全性、可靠性、**高确定性**（行为不随时间/状态随意变——常考）。
- **DO-178B**：目标、过程（计划/开发/综合及子过程）、数据（生命周期产物统称）贯穿安全攸关软件。

## 四、计算机网络

### 功能与指标（★～★★）
- 功能：数据通信、资源共享、管理集中化、分布式处理、负载均衡。
- 性能：速率、带宽（频带 Hz vs 最高数据率 b/s）、吞吐量、时延（发送/传播/处理/排队）、RTT、利用率。
- 非性能：费用、质量、标准化、可靠性、可扩展、易管理维护。

### 通信基础
- **香农公式**：信道容量与带宽、信噪比相关（记符号含义即可应试）。
- 发端处理链：信源编码 → 信道编码 → 交织 → 脉冲成形 → 调制；收端大致逆过程。
- **复用**：TDM / FDM / CDM（如 ADSL 用 FDM）；**多址**：TDMA / FDMA / CDMA。
- **5G 要点**：OFDM 相关优化、大规模 MIMO、毫米波、频谱共享、先进信道编码等；场景 **eMBB / uRLLC / mMTC**；**网络切片**把一张物理网切成多张逻辑独立虚拟网。

### 网络类型与拓扑（★★）
- LAN / WLAN / MAN / WAN / 移动网。
- 拓扑：星（中心故障全瘫）、树、总线、环（单向、不便扩充）、网状（高冗余高成本）。
- **以太网（IEEE 802.3）**：最小帧 64B、最大帧约 1518B（数据最大 1500）；Length/Type 字段含义；CSMA/CD 与最小帧长相关。
- WLAN：无线介质 + 网卡/AP；灵活易扩展。
- WAN：通信子网 + 资源子网；覆盖广、无固定拓扑。
- MAN：覆盖介于 LAN 与 WAN；DQDB（IEEE 802.6）等。
- 移动通信代数：1G FDMA 模拟 → 2G TDMA → 3G CDMA → 4G LTE → 5G。

### 设备、交换、路由、协议与工程（★★）
| 设备 | 大致工作层 |
|------|------------|
| 集线器、中继器 | 物理层 |
| 网桥、交换机 | 数据链路层 |
| 路由器 | 网络层 |
| 防火墙 | 按规则过滤，常作门户 |

- 交换机：学习源 MAC → 查表转发；未知则**泛洪**；表项定时老化；STP 破环；链路聚合提带宽/冗余。
- 路由：IGP（RIP 距离矢量；OSPF/IS-IS 链路状态等）与 EGP（BGP）。
- **OSI 七层**口诀记忆 + **TCP/IP** 四层（应用/传输/网际/网络接口）对应关系。
- **网络工程三环节**：规划 → 设计 → 实施。

## 五、计算机语言与建模

### 语言三类（★★）
- **机器语言**：二进制，直接执行，难写难移植。
- **汇编**：助记符，需汇编后执行，仍偏面向机器。
- **高级语言**：接近自然语言，需编译/解释；可移植性好。

### UML（★★★）
- 与具体编程语言无关的 OO 建模语言；贯穿分析设计全过程。
- **四种事物**：结构、行为、分组、注释。
- **关系**：依赖、关联（含聚合/组合）、实现、泛化（继承）。
  - **聚合**：部分可属多个整体，生命周期可不同。
  - **组合**：部分只属一个整体，生命周期随整体。
- **常用图**：用例、类、对象、构件、组合结构、顺序、通信、定时、状态、活动、部署、制品、包、交互概览等——记「各图强调什么」。
- **用例关系**：`<<include>>` 基用例→子用例（抽出公共、基用例不完整必执行子用例）；`<<extend>>` 子用例→基用例（基用例可独立完整）；泛化即继承。
- **五类视图**：用例（中心）、逻辑、进程、实现、部署。
- **4+1**：「1」= **场景（统一场景）**；多视图体现**关注点分离**。

### 形式化语言（★）
- 用精确语义形式语言描述功能，支持分析与验证。
- 流派：面向对象形式化（Z、VDM、B、Object-Z 等）、面向属性、并发、实时等。
- **Z 语言**：状态–操作风格；模式 = 变量说明 + 谓词约束；基于集合论与数理逻辑。

## 高频题型速查

1. RISC 特点组合 / RISC-V 是否为 x86  
2. 分级存储目的；Cache 命中率平均时间计算  
3. 实时 OS「在被控对象允许时间内处理」  
4. 索引节点直接/一二级间接范围与最大文件长度  
5. 位示图：物理块号 → 字号与位置 0/1  
6. CORBA 中 POA 与 Servant 分工  
7. 嵌入式「高确定性」含义  
8. 5G 网络切片  
9. 设备工作层次；交换机泛洪与 STP  
10. UML include/extend 箭头方向；4+1 中的「1」；多视图=关注点分离
